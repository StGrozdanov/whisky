## What to build

A Customer can open **Селекция** (Catalogue) inside the existing Whisky Finder shell: a list of Whiskies (photo, Origin, price from the In-stock SKU or Ask-us fallback), filterable by Origin and Flavour tags. Rows come from live Supabase. This is not the first page; home stays `/`.

Do not invent a second chrome. Reuse nav, footer, and the preview→prod pipeline from #2.

## Acceptance criteria

- [ ] Catalogue lives in the #2 shell (nav “Селекция” works)
- [ ] Running app reads Catalogue from Supabase Postgres; in-memory is Vitest only
- [ ] Vitest covers listing and Origin / Flavour-tag filters through `Shop` (price rule as in the parent spec)
- [ ] Listing a Whisky in data requires photo, House tasting, Origin, and at least one SKU
- [ ] Playwright e2e for Catalogue is added to the existing preview→prod pipeline
